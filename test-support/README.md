# Изолированный интеграционный тест

`FireworksTestProbe` — тестовый плагин, **не устанавливать на боевой сервер**. В релизный JAR он не включается.

Тест создаёт новый каталог `nordfireworks-test-*`, берёт из существующей тестовой установки только исполняемые файлы ядра/библиотек и уже принятый EULA. Мир, настройки, плагины и данные существующего сервера не копируются. Новая установка слушает только `127.0.0.1:25648`; этот порт должен быть свободен. Выполняйте проверки Paper и Folia последовательно.

Нужны Java 25, Maven и отдельная установка Mineflayer с поддержкой Minecraft 26.2. У этой команды нет подключения к боевому серверу.

```powershell
mvn -B -ntp clean verify
./test-support/build-probe.ps1 -JavaHome $env:JAVA_HOME
node ./test-support/integration.cjs <fresh-nordfireworks-test-directory> <java-executable> <test-server-runtime-directory> <Paper-or-Folia> <mineflayer-node_modules-directory>
```

Тестовый клиент отправляет настоящие `block_place` и `use_item`, принимает `set_cooldown`. Проверяются расход одной ракеты, отказ без расхода при cooldown, смена руки/ячейки, ускорение на элитрах, повторный запуск после окончания cooldown, отмена другим плагином, явное право обхода и reload. Probe читает состояние игрока через его entity scheduler. По окончании клиент отключается, сервер получает `stop`; результаты и журнал остаются в новом тестовом каталоге.

Это проверка функциональности на синтетических данных, а не нагрузочный тест на 1000 игроков и не визуальная проверка реальным человеком.
