# Проверка релиза 1.0.0 — 2026-10-08

Сборка: Java 25, Paper API `26.2.build.129-stable`. Один и тот же JAR проверен на:

- Paper `26.2-132-ver/26.2@19ebc4a`;
- Folia `26.2-7-ver/26.2.x@14b7fee`.

8 JUnit-тестов прошли. На каждом из двух изолированных серверов прошли 8 интеграционных проверок:

1. Включение релизного JAR.
2. Настоящий ручной запуск с земли: расход одной ракеты, получение клиентом `set_cooldown` с группой `minecraft:firework_rocket` и длительностью 40 тиков.
3. Отказ при смене руки и ячейки во время cooldown, без расхода заблокированных ракет.
4. Настоящий запуск в полёте на элитрах: одна ракета принимается, следующие до окончания cooldown не расходуются.
5. Повторный запуск после окончания cooldown.
6. Отмена ускорения другим плагином: ни расхода ракеты, ни нового cooldown.
7. Явно выданное право `nordfireworks.bypass` отключает выдачу нового cooldown.
8. Reload и отсутствие ошибок обработчиков/владения регионом.

Тестовые установки слушали только loopback. Использовались новый синтетический мир, тестовый клиент и companion-плагин из `test-support`; рабочие миры, авторизация, конфиги и сервер не затрагивались. Обе тестовые установки штатно остановлены. Companion-плагин отсутствует в релизном JAR.

Не проводились: нагрузочный тест на 1000 игроков, визуальная проверка человеком, тест на версиях Minecraft кроме 26.2. Получение стандартного cooldown-пакета проверено программно.
