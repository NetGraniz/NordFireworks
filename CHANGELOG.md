# Changelog

## 1.0.0 — 2026-10-08

- Общая перезарядка ручных запусков фейерверков с земли и ускорений на элитрах: по умолчанию 40 тиков.
- Стандартный индикатор предмета, обе руки и смена ячеек; учитываются кастомные cooldown-группы.
- Один JAR для Paper/Folia 26.2; Java 25.
- Настройка `cooldown-ticks`, команда `/nordfireworks reload`, отдельное право обхода без автоматического предоставления операторам.
- Без фоновых задач, сетевых запросов и баз данных.
- Пройдены unit-тесты и изолированные игровые проверки на Paper и Folia; подробности в `TESTING.md`.

Раздатчики, арбалеты и скорость полёта не ограничиваются. Боевой сервер автоматически не изменяется.
